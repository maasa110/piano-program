# ピアノ発表会プログラム

Excelの演目表から、A4二つ折り（A5見開き）の発表会プログラムを作成・印刷できるWebアプリです。
スマホ・タブレット・PCのブラウザで動作し、「ホーム画面に追加」でアプリとして使えます。

## 使い方

1. 「Excelデータ」タブで演目表（.xlsx）を読み込む（見本Excelもダウンロードできます）
2. 「表紙レイアウト」「文字スタイル」「背景画像」で見た目を調整
3. 「印刷・PDF出力」から A4・横・余白なし で印刷（1枚目＝表紙/裏表紙、2枚目＝中面）

### Excelの列構成

| 種別 | 氏名 | 学年 | 曲名1 | 曲名2 |
|---|---|---|---|---|

- 1行目は見出し行
- シート名がクラス名になります
- 種別「項目」＝見出し行、「イベント／企画／ゲーム」を含む＝色付き行

## データの保存について

入力内容は各自の端末のブラウザ内にのみ保存され、サーバーには送信されません。
別の端末へ移すときは「データ書き出し」「データ読み込み」を使います。
